# Google Search Keywords Analytics Dashboard
This Power BI project presents a comprehensive analysis of Google search trends for various tech-related keywords including AWS, Azure, Agile, Computer Science, and DevOps. The dashboard offers insights into keyword popularity, trends over time, and rising vs top keywords.

# 📊 Project Overview
This interactive dashboard is designed to:
  1.Analyze keyword trends over the last several years.
  2.Track performance based on date ranges.
  3.Compare top vs rising keywords.
  4. Monitor global interest geographically.

# 🧰 Tools Used
  1.Power BI Desktop
  2.Google Trends Data
  3.DAX, Power Query

# 🚀 Getting Started
To explore this dashboard:
  1.Clone or download this repository.
  2.Open Google_dashboard.pbix using Power BI Desktop.
  3.Connect with updated keyword data (if applicable).
  4.Interact with the dashboard tabs for insights.
